Mengenal Bahasa Pemrograman


Bahasa pemrograman digunakan untuk memberikan instruksi kepada komputer. Setiap bahasa mempunyai karakteristik dan kegunaan yang berbeda.
Seorang programmer sebaiknya memahami konsep pemrograman, bukan hanya menghafal sintaks.

Contoh bahasa Pemrograman

  1. pyton
  2. Java
  3. JavaScript
  4. PHP
  5. C++
  6. Dart

    Istilah Bahasa Pemrograman

    Syntax
    Aturan penulisan kode dalam sebuah bahasa pemrograman.
    Variable
    Tempat untuk menyimpan sebuah nilai atau data
    Function
    Kumpulan instruksi yang dapat di panggil untuk melakukan tugas tertentu.
    Library
    Kumpulan kode yang dapat digunakan kembali dalam program.

    Tips Memilih Bahasa
