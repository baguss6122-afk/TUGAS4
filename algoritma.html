Apa Itu Algoritma?


Algoritma adalah langkah-langkah sistematis untuk menyelesaikan suatu masalah.

Sebelum membuat program, programmer sebaiknya memahami masalah dan solusi yang akan dibuat.

Langkah Membuat Algoritma

  1. Memahami masalah
  2. Menentukan input
  3. Menentukan proses
  4. Menentukan output
  5. Menulis langkah penyelesaian
  6. Menguji solusi

Struktur Dasar Algoritma

  • Sequence
  • Selection
  • Iteration

Contoh Struktur

  1. Sequence
    • Input
    • Process
    • Output
  2. Selection
    • IF
    • IF ELSE
    • SWITCH
  3. Iteration
    • FOR
    • WHILE
    • DO WHILE

Istilah Algoritma

Input
Data yang dimasukkan ke dalam program
Process
Tahapan pengolahan data
Output
Hasil yang diberikan oleh program
Flowchart
Diagram yang digunakan untuk menggambarkan alur algoritma

Contoh Algoritma Sederhana

  1. Masukkan nilai pertama
  2. Masukkan nilai kedua
  3. Jumlahkan kedua nilai
  4. Tampilkan hasil

Algoritma yang baik harus jelas, logis, dan sistematis
